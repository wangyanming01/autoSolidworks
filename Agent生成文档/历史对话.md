# 水阀阀芯参数化与自动生成项目概述

## 一、项目背景

目前已有一套通过基础单元、圆周阵列和轴向阵列搭建的水阀阀芯模型，典型结构为三层、每层六个单元。

现有建模方式能够生成固定结构，但面对不同壁厚、尺寸、分区数量及流道布局时，仍需要手动修改多个草图、特征和隔板。项目希望把这些操作转化为统一、可重复的参数化生成过程。

设计上，阀芯中心需要保留空腔，避免内侧塑料过厚或形成实心区域，减少材料分布不均的问题。**现阶段保留这一几何要求，暂不展开中心流道的功能设计，也尚未进行成型分析。**

## 二、项目总体目标

建立一套以基础模型为模板、通过 SOLIDWORKS API 驱动的阀芯生成方案：

**整体设计参数 → 基础模型更新 → 完整阀芯阵列 → 指定隔板删除 → 定制流道模型。**

最终希望实现：

- 输入整体尺寸、壁厚、分区数量等要求，自动转换成基础模型参数。
- 修改参数时，三个板的位置关系保持正确。
- 引用基础模型，利用共同轴线和参考面完成定位。
- 自动生成圆周及轴向重复结构。
- 按流道需求删除指定隔板，保留其他结构。
- 检查重建结果、实体数量以及预期的流道连通情况。

目前重点是让基础模型成为稳定的参数化模板，尚未进入完整自动生成程序的实现阶段。

## 三、已经明确的设计规则

### 1. 基础单元结构

基础模型由三个独立实体组成：

| 实体 | 平面轮廓参数 | 轴向控制 |
|---|---|---|
| 底板 | 外半径 R0、内半径 R1、中心角 theta | 从 alpha1 拉伸到 alpha2 |
| 内板 | 外半径 R1、内半径 R2、中心角 theta | 从 alpha1 拉伸到 alpha3 |
| 侧板 | 新版简化轮廓、侧板厚度 | 从 alpha1 拉伸到 alpha3 |

基本尺寸关系为：

- `R0 > R1 > R2 > 0`
- 内板厚度为 `R1 − R2`
- 底板厚度由 alpha1—alpha2 的距离控制。
- 壁高由 alpha1—alpha3 的距离控制。

三个实体不提前合并，允许存在设计需要的重叠，以保留后续分别删除的能力。

### 2. 共同定位关系

三个板应使用统一的圆心、方向和参考面：

- O：共同圆心。
- 中心轴：用于圆周阵列及引用模型定位。
- L0：固定的扇区起始方向，同时作为侧板厚度中线。
- L_theta：扇区活动边方向。
- alpha1～alpha3：控制三个板的轴向位置。

侧板厚度围绕 L0 对称变化。改变 theta 时，L0 和侧板方向不动，另一条扇区边转动，底板与内板同步变化。

不强制新建一个独立的主控草图；关键是共同参数和参考只有一个来源，并且各草图真正引用它们。

### 3. 阵列规则

当前采用完整圆周等分：

`theta = 360° / N`

其中 N 为每圈单元数量，当前为 6。theta 不再作为与 N 相互独立的输入。

轴向阵列间距跟随壁高。当前为三层；层数、总高度和端部封闭结构之间的完整参数关系，还需要进一步细化。

### 4. 流道定制规则

先生成完整结构，再删除指定隔板实体，不通过删除基础模型上游特征来控制某个局部位置。

计划用“层号＋圆周单元号＋板类型”描述待删除对象。还需要解决：

- 如何将逻辑编号稳定映射到实际实体。
- 重建或改变阵列数量后如何重新识别实体。
- 删除隔板后，其他实体的重叠材料是否仍会阻挡流道。
- 如何判断应该连通和应该隔断的位置。

## 四、当前分析情况

### 1. 已确定新版模型作为基准

后续以你重新制作的 `基础模型v2.SLDPRT` 为基础。

新版侧板采用简化形状，**不再沿用旧版端部折线及固定退距规则**。但简化侧板两端与 R0、R1 的准确几何绑定，仍需在草图中核实，不能直接套用旧模型规则。

### 2. 已核实的模型结构

实际检查确认：

- 模型包含底板、内板、侧板三个独立实体。
- alpha1～alpha3 已建立。
- axis0 由前视基准面与右视基准面相交得到。
- axis1 由 alpha1 与右视基准面相交得到，可作为 L0 的方向参考。
- 底板拉伸已经使用 alpha1、alpha2 作为起止参考。
- 底板和侧板原有草图存在欠定义情况。

### 3. 已发现的关键问题

**模型外观看起来正确，不代表变参时仍能保持正确。**

底板就是一个已经验证的例子：原来具有正确的圆弧和外观角度，但缺少活动边通过圆心的明确约束。仅补上半径与角度尺寸后，草图仍然欠定义；补齐径向关系后，才达到完全定义。

因此，后续检查不能只关注尺寸值，还必须核对：

- 圆心是否一致。
- 起始方向是否固定。
- 边界是否真正保持径向。
- 共享尺寸是否实际联动，而不是恰好数值相等。
- 是否存在重复约束、循环引用或不必要的固定关系。

## 六、未来实施计划

### 第一阶段：完成基础模型标准化

- 完成内板对底板 R1、theta 的关联，并建立 R2 控制。
- 核实新版侧板的端部规则。
- 完成侧板关于 L0 的对称厚度和径向位置约束。
- 核对参考面的依赖关系及三个拉伸的绑定。
- 保持三个独立实体，不新增无必要的实体。

验收重点：关键草图完全定义，基准尺寸下重建正常，保持当前设计外形。

### 第二阶段：建立整体参数映射

确定用户输入与派生参数的边界。例如：

| 整体要求 | 基础模型中的映射 |
|---|---|
| 外径 | R0＝外径÷2 |
| 内板厚度 | R1−R2 |
| 底板厚度 | alpha2 相对 alpha1 的距离 |
| 壁高 | alpha3 相对 alpha1 的距离 |
| 侧板厚度 | L0 两侧各偏置厚度的一半 |
| 每圈分区数 N | theta＝360°÷N |

其中，内板厚度变化时究竟固定 R1 还是固定 R2，以及总高度如何分配到层高、底板和端部结构，仍需明确，避免出现相互冲突的输入。

### 第三阶段：验证变参稳定性

分别改变半径、板厚、壁高和 N，检查：

- 三个板的位置关系是否保持。
- 是否出现缝隙、非预期重叠或轮廓翻转。
- 是否发生重建错误或实体数量变化。
- 参数恢复后能否回到基准模型。

完全定义只是起点，变参通过才说明模板可用于自动生成。

### 第四阶段：实现 API 生成流程

- 读取并校验输入参数。
- 更新基础模型并检查重建结果。
- 引用模型，以共同参考完成定位。
- 生成圆周和轴向阵列。
- 建立实体编号及识别规则。
- 保存生成结果，记录失败原因。

### 第五阶段：实现定制流道

先用少量明确案例验证删除规则，再扩展到复杂流道：

- 同层相邻分区连通。
- 相邻层之间连通。
- 多处隔板组合删除。
- 保留必要边界，避免非预期串通。

最终同时检查剩余材料和流道空间，不能仅以“删除操作成功”作为验收依据。
