# SolidWorks 参数化与阵列生成运行说明

## 1. 快速开始：完整水阀阀芯阵列建模、定制流道清除与顶盖装配（推荐）

直接通过配置文件，在 SolidWorks 中全自动完成：
1. 基础三板单元尺寸调整与方程式驱动
2. 8 扇区圆周阵列与多层轴向线性阵列（层高自动堆叠）
3. 3D 几何特征扫描与实体逻辑编号（`L{layer}_S{sector}_{body_type}`）
4. 按 `delete_bodies` 清单准确清除指定实体（生成定制流道）
5. **在零件中自动插入顶盖实体并精确定位装配（`alpha0` 底面与最顶层顶面贴合，中心轴与 `axis0/axis1` 重合）**
6. 静默持久化保存并自动关闭文档，不在前台占用界面。

```bash
python scripts\generate_valve_core_array.py --config configs\valve_core_array.example.json --output outputs\generated\valve_core_array_final.SLDPRT --overwrite
```

### 运行后生成结果：
- **SolidWorks 完整模型**：[outputs/generated/valve_core_array_final.SLDPRT](outputs/generated/valve_core_array_final.SLDPRT)
- **特征树生成**：
  - `阵列(圆周)1`：按 6 个扇区在中心轴生成圆周阵列（18 实体）
  - `阵列(线性)1`：按 3 层自动堆叠生成轴向线性阵列（54 实体）
  - `实体-删除/保留 1`：根据 `delete_bodies` 清单准确删除 5 个目标实体（49 实体）
  - `顶盖` & `实体-移动/复制1`：插入顶盖零件并精确定位在顶面 $Y=99.0\text{ mm}$（最终模型高度 102 mm，共 50 个实体）
- **实体总数**：从 $54$ 个实体清除 $5$ 个流道实体后，加入 $1$ 个顶盖实体，最终保留 **$50$ 个实体**。
